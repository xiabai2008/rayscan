# WVS v16.0 更新日志

## 发布信息
- 版本: 16.0.0
- 日期: 2026-04-17
- 基于版本: v15.0

## 🎯 核心改进

### 1. 多阶段 SQL 注入验证
**问题**: v15.0 只做简单的错误检测，误报率高，漏报率高

**改进**:
- 阶段 1: 错误型注入（最快，检测 SQL 错误信息）
- 阶段 2: UNION 注入（列数探测）
- 阶段 3: 布尔盲注（响应对比）
- 阶段 4: 时间盲注（多次验证减少误报）

**参考**: sqlmap 的多阶段验证机制

### 2. 上下文感知 XSS 检测
**问题**: v15.0 不区分注入上下文，payload 选择不智能

**改进**:
- 自动分析注入点上下文（HTML body / 属性 / JavaScript / URL）
- 根据上下文选择最佳 payload
- CSP 检测和绕过建议
- 浏览器兼容性检测

**参考**: OWASP ZAP 的上下文感知扫描

### 3. 智能爬虫
**问题**: v15.0 爬虫能力弱，只爬静态链接

**改进**:
- 智能表单识别和填充
- API 端点自动发现（从 JS、HTML 中提取）
- SPA 检测（React/Vue/Angular）
- 认证态保持
- 垃圾页面过滤

**参考**: Burp Suite 的爬虫设计

### 4. WAF 规避
**问题**: v15.0 无 WAF 规避能力

**改进**:
- SQL 注入 WAF 规避（内联注释、大小写混合、编码绕过）
- XSS WAF 规避（空白字符替代、标签变形）
- 自动检测 WAF 并尝试绕过

**参考**: sqlmap 的 tamper scripts

### 5. 数据库指纹识别
**问题**: v15.0 不识别数据库类型

**改进**:
- 基于错误信息识别数据库（MySQL/PostgreSQL/Oracle/MSSQL/SQLite）
- 根据数据库类型选择特定 payload
- 报告中显示数据库类型

### 6. 时间盲注优化
**问题**: v15.0 时间盲注误报率高（网络波动）

**改进**:
- 多次测量取平均值
- 与基准响应对比
- 阈值可配置（默认 3 秒）

### 7. 突变 XSS（mXSS）检测
**新增**: 检测 DOM 净化器的突变漏洞

### 8. 云元数据 SSRF
**新增**: 检测 AWS/GCP/Azure 元数据端点访问

## 📊 Payload 增强

- 错误型: 10+ → 15+
- UNION 型: 5 → 10+
- 布尔盲注: 4 → 8+
- 时间盲注: 5 → 12+
- WAF 规避: 0 → 10+
- 数据库特定: 0 → 15+

- WAF 规避: 0 → 5
